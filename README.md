# ⚡ INVOICE INTELLIGENCE

A real-time, multi-agent enterprise invoice intelligence tool built with Python, Streamlit, and the Google GenAI SDK.

## 🚀 Architecture & Paradigm
This application uses a multi-agent pipeline to audit unstructured vendor documents, parsing raw text into strict JSON schemas and evaluating risk tiers.

## 🛠️ Tech Stack
- **Frontend:** Streamlit & Neo-Brutalist CSS
- **Backend:** Python & Google GenAI SDK
- **Features:** Risk scoring, test data cycling, and JSON/CSV export.
